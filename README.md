# Fireworks

A Pygame fireworks animation with synthesized launch and explosion sound
effects. Click in the window to launch a firework, and press `Esc` to exit.

## Run on Windows

Use Python 3.12, then install the dependency and start the app:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe .\fireworks.py
```

To run or debug in VS Code, select the `.venv` Python interpreter and press
`F5` (or use **Run Python File**).
